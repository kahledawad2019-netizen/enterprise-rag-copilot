# Backend container dependencies.
#
# This is deliberately NOT the project's requirements.lock.txt. That file pins
# 225 packages including streamlit, jupyter, matplotlib and the PyTorch
# reranker - a ~3 GB image to serve a JSON API that uses none of them.
#
# What is excluded and why:
#   streamlit, jupyter, matplotlib   the container serves JSON, not a UI
#   torch, sentence-transformers     the cross-encoder reranker. The
#                                    independent evaluation found reranking
#                                    is NOT statistically distinguishable
#                                    from hybrid (+0.023 NDCG, CI [-0.013,
#                                    +0.059], p=0.217) at 36x the latency.
#                                    Paying 2.5 GB and a cold start for that
#                                    is not a trade worth making in a
#                                    container. The reranker degrades to a
#                                    no-op; hybrid ranking is used directly.
#
# The free cloud target is Neon PostgreSQL. The same application also keeps a
# SQL Server adapter for local SSMS development, but the production container
# only ships the PostgreSQL driver and uses DATABASE_BACKEND=postgresql.
